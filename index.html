Perangkat Jaringan & Mekanisme Pengiriman Data

Ringkasan Informatika SMA/MA Kelas XI

1. Dasar Jaringan Komputer

Jaringan komputer digunakan untuk menghubungkan komputer dan perangkat agar dapat berkomunikasi serta bertukar data.

Server Client NIC Kabel Switch Router
Mekanisme:
Perangkat terhubung melalui kabel atau sinyal nirkabel. Data kemudian dikirim menggunakan protokol jaringan dari perangkat sumber menuju perangkat tujuan.

2. Komputer Server

Server adalah komputer yang menyediakan layanan kepada komputer client, seperti penyimpanan file, data, aplikasi, web, dan akses internet.

Mekanisme:
Client meminta layanan → Server memproses permintaan → Server mengirimkan data atau layanan kembali ke client.

3. Komputer Client

Client adalah komputer atau perangkat yang digunakan pengguna untuk mengakses data dan layanan dari server.

Mekanisme:
Client mengirim permintaan → Server menerima → Server memberikan layanan → Client menerima hasil.

4. Kartu Jaringan (NIC)

NIC atau Network Interface Card adalah perangkat jaringan yang memungkinkan komputer terhubung dan berkomunikasi dalam jaringan.

Fungsi: Menghubungkan komputer ke jaringan dan membantu proses pengiriman serta penerimaan data.

5. Kabel dan Media Jaringan

Kabel Koaksial

Kabel dengan konduktor tembaga di bagian tengah yang dilindungi lapisan isolasi dan pelindung logam.

Kelebihan: tahan gangguan dan dapat digunakan untuk jarak jauh.
Kekurangan: sulit dipasang.

Kabel UTP

Unshielded Twisted Pair terdiri dari delapan kawat tembaga yang dipilin berpasangan dan umum digunakan pada LAN.

Konektor: RJ-45

Kabel STP

Shielded Twisted Pair memiliki pelindung pada pasangan kabel sehingga lebih tahan terhadap gangguan listrik dan radio.

Kekurangan: lebih mahal dan pemasangannya lebih sulit.

Fiber Optic

Kabel yang menggunakan serat kaca atau plastik untuk mengirim data menggunakan cahaya.

Kelebihan:
  • Kecepatan tinggi
  • Jarak transmisi jauh
  • Bandwidth besar
  • Tahan terhadap gangguan listrik
Jenis: Single Mode dan Multimode.

6. Repeater

Repeater berfungsi memperkuat atau memulihkan sinyal yang melemah karena jarak transmisi yang jauh.

Mekanisme:
Sinyal melemah → Repeater menerima sinyal → Sinyal diperkuat → Sinyal diteruskan kembali.

7. Hub

Hub digunakan untuk menghubungkan beberapa perangkat dalam jaringan dan membagi koneksi melalui beberapa port.

Hub Aktif

Memiliki sumber listrik sendiri dan dapat membersihkan, memperkuat, serta meneruskan sinyal.

Hub Pasif

Hanya meneruskan sinyal tanpa membersihkan atau memperkuatnya.

Mekanisme:
Data masuk ke hub → Hub meneruskan data ke perangkat yang terhubung.

8. Bridge

Bridge digunakan untuk menghubungkan dua atau lebih jaringan lokal serta mengurangi lalu lintas data yang tidak diperlukan.

Mekanisme:
Bridge membaca alamat MAC sumber dan tujuan → menentukan apakah data perlu diteruskan → data diteruskan hanya jika diperlukan.

Bridge bekerja pada Data Link Layer.

9. Switch

Switch menghubungkan berbagai perangkat dalam jaringan dan mengatur pengiriman data agar lebih efisien.

Mekanisme:
Data masuk → Switch membaca alamat tujuan → Switch menentukan port tujuan → Data dikirim langsung ke perangkat tujuan.

Berbeda dengan hub, switch tidak harus mengirim data ke seluruh perangkat.

10. Router

Router menghubungkan beberapa jaringan dan menentukan jalur yang harus dilewati paket data.

Mekanisme:
Paket datang → Router membaca alamat IP tujuan → Router melihat informasi jaringan/routing → Router menentukan jalur → Paket diteruskan ke jaringan tujuan.

Jenis Router

  • Router Dedicated: perangkat khusus yang dibuat untuk menjalankan fungsi router.
  • Router PC: komputer yang difungsikan sebagai router.

Tanggung Jawab Router

  • Mencegah data melewati jalur yang tidak diperlukan.
  • Mengarahkan data menuju jaringan yang tepat.
  • Membantu memastikan informasi sampai ke komputer tujuan.

11. Perbandingan Perangkat

Perangkat Fungsi Utama
Server Menyediakan layanan kepada client
Client Mengakses layanan dari server
NIC Menghubungkan komputer ke jaringan
Repeater Memperkuat atau memulihkan sinyal
Hub Meneruskan data ke perangkat yang terhubung
Bridge Menghubungkan segmen jaringan dan menyaring data
Switch Mengirim data ke perangkat tujuan secara efisien
Router Menentukan jalur paket antarjaringan

12. Alur Pengiriman Data Sederhana

Client → NIC → Switch/Hub → Router → Jaringan Tujuan → Server/Client Tujuan

Setiap perangkat mempunyai tugas berbeda. NIC menyediakan koneksi, switch mengatur pengiriman dalam jaringan, router menentukan jalur antarjaringan, sedangkan server menyediakan layanan.

Perangkat Jaringan dan Mekanisme Pengiriman Data

Informatika SMA/MA Kelas XI

1. Jaringan Komputer

Jaringan komputer adalah sistem yang menghubungkan komputer dan perangkat agar dapat berkomunikasi serta bertukar data.

Server Client NIC Switch Router Kabel
Mekanisme dasar:
Perangkat terhubung → data dibuat menjadi paket → paket dikirim melalui jaringan → paket diarahkan → paket diterima oleh perangkat tujuan.

2. Komputer Server

Server adalah komputer yang menyediakan layanan kepada komputer client, seperti penyimpanan file, data, aplikasi, web, dan akses internet.

Mekanisme:
Client mengirim permintaan → Server menerima → Server memproses → Server mengirimkan hasil kepada client.

3. Komputer Client

Client adalah komputer atau perangkat yang digunakan pengguna untuk mengakses data dan layanan dari server.

Mekanisme:
Client meminta layanan → Server memberikan layanan → Client menerima dan menggunakan hasilnya.

4. Kartu Jaringan (NIC)

NIC atau Network Interface Card adalah perangkat yang memungkinkan komputer terhubung dan berkomunikasi dengan jaringan.

Fungsi:
Menghubungkan komputer dengan jaringan serta membantu pengiriman dan penerimaan data.

5. Kabel dan Media Jaringan

Kabel Koaksial

Memiliki konduktor tembaga di tengah yang dilindungi isolasi dan pelindung logam.

  • Tahan terhadap gangguan sinyal.
  • Dapat digunakan untuk jarak relatif jauh.
  • Kekurangannya sulit dipasang.

Kabel UTP

Unshielded Twisted Pair terdiri dari delapan kawat tembaga yang dipilin berpasangan dan umum digunakan pada LAN.

  • Murah.
  • Mudah dipasang.
  • Menggunakan konektor RJ-45.
  • Lebih rentan terhadap gangguan listrik dibanding STP.

Kabel STP

Shielded Twisted Pair memiliki pelindung untuk mengurangi gangguan listrik dan radio.

  • Lebih tahan terhadap gangguan.
  • Dapat digunakan pada lingkungan dengan banyak gangguan.
  • Lebih mahal dan pemasangannya lebih sulit.

Fiber Optic

Fiber optic menggunakan cahaya untuk mengirimkan data melalui serat kaca atau plastik.

  • Kecepatan tinggi.
  • Bandwidth besar.
  • Jarak transmisi jauh.
  • Tahan terhadap gangguan listrik.
  • Cocok untuk jaringan WAN.

Jenis fiber optic: Single Mode dan Multimode.

6. Repeater

Repeater digunakan untuk memperkuat atau memulihkan sinyal yang melemah akibat jarak transmisi.

Sinyal melemah → Repeater menerima → Sinyal diperkuat → Sinyal diteruskan

7. Hub

Hub menghubungkan beberapa perangkat dan membagi koneksi melalui beberapa port.

Hub Aktif

Memiliki sumber listrik sendiri dan dapat membersihkan, memperkuat, serta meneruskan sinyal.

Hub Pasif

Hanya meneruskan sinyal tanpa memperkuatnya.

Data masuk ke hub → Hub meneruskan data ke perangkat yang terhubung.
Kelemahan hub: Data dapat diteruskan ke banyak perangkat sehingga traffic dan kemungkinan tabrakan paket dapat meningkat.

8. Bridge

Bridge digunakan untuk menghubungkan dua atau lebih jaringan lokal dan mengurangi lalu lintas data yang tidak diperlukan.

Bridge membaca alamat MAC sumber dan tujuan → menentukan apakah paket perlu diteruskan → paket diteruskan hanya jika diperlukan.

Bridge bekerja pada Data Link Layer.

9. Switch

Switch menghubungkan perangkat dalam jaringan dan mengatur pengiriman data agar lebih efisien.

Data masuk → Switch membaca alamat tujuan → Menentukan port → Data dikirim ke tujuan

Switch dapat mengirim data langsung ke perangkat tujuan, sehingga lebih efisien dibandingkan hub.

10. Router

Router menghubungkan beberapa jaringan dan menentukan jalur yang harus dilewati paket data berdasarkan alamat tujuan.

Paket masuk → Cek alamat IP → Cari jalur terbaik → Paket diteruskan → Jaringan tujuan

Jenis Router

  • Router Dedicated: perangkat khusus yang dibuat untuk menjalankan fungsi router.
  • Router PC: komputer yang difungsikan sebagai router.

Tanggung Jawab Router

  • Menentukan jalur paket data.
  • Menghindari jalur yang tidak diperlukan.
  • Mengarahkan data menuju jaringan tujuan.
  • Membantu memastikan informasi sampai ke tujuan.

11. Enkapsulasi Paket Data

Sebelum dikirim melalui jaringan, data dibungkus dengan informasi tambahan yang disebut header.

Header dapat berisi informasi seperti alamat pengirim, alamat penerima, dan informasi posisi paket.

Data ↓ Diberi Header ↓ Menjadi Paket ↓ Dikirim melalui Jaringan ↓ Diterima Tujuan ↓ Data Disusun Kembali
Tujuan enkapsulasi:
Membantu jaringan mengetahui asal, tujuan, dan informasi yang diperlukan agar paket dapat dikirim dan disusun kembali dengan benar.

12. Mekanisme Routing

Paket data dapat melewati rute yang berbeda bergantung pada kondisi jaringan saat pengiriman.

Contoh:
Jika jalur utama mengalami gangguan, jaringan dapat menggunakan jalur alternatif sehingga paket tetap dapat mencapai tujuan.

Keuntungan

  • Membagi beban jaringan.
  • Menjaga efisiensi lalu lintas data.
  • Dapat menggunakan jalur alternatif.
  • Meningkatkan keandalan pengiriman data.

13. Informasi yang Digunakan Router

Router menggunakan informasi jaringan untuk menentukan ke mana paket harus diteruskan.

Informasi Fungsi
Alamat tujuan Menentukan jaringan tujuan paket.
Prioritas koneksi Membantu memilih jalur yang sesuai.
Aturan lalu lintas Mengatur bagaimana paket ditangani.
Kondisi jaringan Membantu memilih jalur yang lebih optimal.

14. Menelusuri Paket Data

Pada Windows, perjalanan paket menuju suatu alamat dapat ditelusuri menggunakan perintah tracert.

Langkah-langkah

  1. Buka Command Prompt.
  2. Ketik cd \ untuk kembali ke direktori utama.
  3. Ketik tracert diikuti alamat tujuan.
Contoh:

tracert www.amazon.com

Perintah tersebut menampilkan router atau hop yang dilewati paket dari komputer menuju tujuan.

Contoh Perintah Lain

tracert google.com
tracert youtube.com
tracert github.com

Setiap hop menunjukkan salah satu titik jaringan yang dilewati paket sebelum mencapai tujuan.

15. Masalah Trafik dalam Jaringan

Ketika jaringan semakin besar, penggunaan hub dan peningkatan jumlah node dapat menyebabkan berbagai masalah.

A. Scalability

Scalability adalah kemampuan jaringan untuk berkembang mengikuti peningkatan jumlah perangkat dan kebutuhan data.

Pada jaringan berbasis hub, bandwidth harus dibagi sehingga pertumbuhan jaringan dapat menurunkan kinerja.

Masalah: Jumlah perangkat bertambah → kebutuhan bandwidth meningkat → kinerja jaringan dapat menurun.

B. Latency

Latency adalah waktu yang diperlukan paket untuk mencapai tujuan.

Semakin banyak node → semakin banyak perangkat berbagi jaringan → waktu tunggu meningkat → latency meningkat.

Pengiriman file besar juga dapat memperlambat komunikasi perangkat lain.

C. Kegagalan Jaringan

Masalah pada satu perangkat dalam jaringan berbasis hub dapat memengaruhi perangkat lain, terutama akibat pengaturan yang tidak tepat atau broadcast berlebihan.

Solusi:
Menggunakan switch untuk membatasi broadcast dan mengatur lalu lintas data dengan lebih baik.

D. Tabrakan Antar Paket Data

Pada Ethernet, CSMA/CD digunakan untuk membantu mencegah terjadinya tabrakan data.

Node ingin mengirim → memeriksa jaringan → jika jaringan tersedia, data dikirim → jika terjadi tabrakan, paket hilang → transmisi diulang.
Catatan: Semakin banyak node berada dalam satu segmen jaringan, semakin besar potensi terjadinya tabrakan paket.
